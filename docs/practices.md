# Practices

## Review route
A GitHub pull request against `main`. A maintainer merges.

## Git
Branches: `<issue-number>-<slug>`. Commits: imperative summary, no prefix. The commit that completes a slice ends with `Fixes #<issue-number>`.

## Prerequisites
Go at the version in `go.mod`. `jq` and `zip` for packaging. `gh` logged in for the issue tracker and pull requests.
